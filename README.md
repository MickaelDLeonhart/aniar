# 🎬 aniar - Arabic Anime Streaming Tool

A command-line tool for streaming anime with Arabic subtitles from anime4up. Built specifically for Arabic-speaking anime fans, And it doesn't collect any kind of data. 


## ✨ Features

- 🎬 **Arabic Subtitles** - Focus on Arabic-subbed content
- 🔍 **Smart Search** - Find anime by Arabic or English names
- 📺 **Multiple Sources** - Auto-selects best working video source
- ⚡ **Fast & Lightweight** - Minimal dependencies, runs anywhere
- 📝 **Watch History** - Tracks your progress automatically
- 🎨 **Beautiful Interface** - Clean UI with emoji support
- 🔄 **Auto Update** - Easy updates with one command
